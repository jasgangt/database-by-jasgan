# database-by-jasgan

# 📝 Web Daftar Tugas Bersama
Proyek ini adalah aplikasi web sederhana yang terhubung dengan **Supabase Database**.

### ✨ Fitur:
- Input data secara real-time.
- Database publik berbasis Cloud.
- Tampilan responsif dengan CSS.

### 🛠️ Teknologi yang Digunakan:
- HTML5 & CSS3
- JavaScript (ES6)
- [Supabase](https://supabase.com/) sebagai Backend-as-a-Service.
